# えびす時空さんぽ（試作）

地図で恵比寿さんまで歩き、着いたらその場所の水害の歴史を見て、最後にそこから見えた空を見る試作。企画は [planning/concept.md](../../planning/concept.md)。

## 流れ

1. **地図**：デモの3体と現在地を地図に出す。浸水想定（想定最大規模）を重ねられる
2. **恵比寿さんの前・水**：浸水想定の深さを大人の背の高さと比べて見せる。建ってから経験した佐賀市の水害を年表で出す
3. **恵比寿さんの前・空**：その場所から見た、建った年と今年の 11月15日の夜空

### かざすモード（空の画面の「スマホを空にかざす」）

- カメラ（背面）と向きのセンサーの許可を求め、画面いっぱいにカメラの映像を出す。その上に星・惑星・地平線・方角を透かして重ねる
- 重ねる空は「今の空」（今この瞬間）と「建った年の空」（建った年の同じ日付・同じ時刻）を切り替えられる。30秒ごとに計算し直す
- 夜モード（最初はオン）：映像を明るくし（露出を変えられる Android では露出も上げる）、操作ボタンを暗くしてまぶしさを抑える
- 星の位置をカメラの映像に合わせるため、画角を画面の長い辺で 63° にしている（iPhone の広角カメラの目安）
- カメラを使えなければ星だけ、向きのセンサーが使えなければドラッグで見回せる。「やめる」か Esc で戻る

恵比寿さんから 40m 以内に入ると「着いた」ボタンになる。会場でのデモ用に、離れていても「ここに着いたことにする（デモ）」で進められる。

画面の切り替えは URL のハッシュで行う。`#/` が地図、`#/spot/mojitai` などが恵比寿さんの前。

## 開き方

データを `fetch` で読むので、ファイルを直接開くのではなく、**リポジトリの直下で**ローカルサーバーを立てる。

```sh
python3 -m http.server 8765
# → http://localhost:8765/prototype/sanpo/
```

## 公開（Cloudflare）

リポジトリの直下で `./scripts/deploy-sanpo.sh`（ビルド → デプロイ → Access の確認）。Access でチームだけに絞る手順も含めて [docs/cloudflare/README.md](../../docs/cloudflare/README.md) に書いた。

## 画面の幅

DESIGN.md の区切り（640px / 1024px）に合わせて組み替える。

| 幅 | 地図 | 恵比寿さんの前 |
| --- | --- | --- |
| 〜639px（スマホ） | 地図の下に一覧 | 水 → 「この場所から見えた空へ」 → 空 の縦並び。空の操作ボタンは指で押しやすい大きさ |
| 640〜1023px | 同上 | 同上 |

## 星空の細かいこと

- 1900年より前は街明かりなし（6等星まで）、1900年以降は市街地（3.5等星まで）として描く。限界等級は推定値
- 夕方の薄明（太陽高度 -18°〜-6°）は暗い星を減らす
- 時刻を 18:00〜翌4:00 で動かせる
- 「方角を見る」：ドラッグか方角のボタンで見回す。「全天を見る」：真上が中心の星図
- 「スマホを空にかざす」：端末の向きのセンサーで、向けた方角の空を出す
- 見えている月と惑星の方角・高さを、文字でも表示する（読み上げ用に canvas の説明文も更新する）
- 文字鯛恵比須（`isHighlight`）の 1822年の空では、木星を丸で囲む

## えびすさんが歩く（walk.html、試作）

`/prototype/sanpo/walk` で開く別の画面。地図の試作とはまだつないでいない。

- えびす像と、ときどき現れる佐賀七賢人（レアキャラ）が、OpenStreetMap の徒歩ルート（寶富 → 八坂 → 文字鯛、約443m）に沿って歩く。カメラの映像に重ねられる
- キャラクターは板ポリゴン調（白い縁取りと厚みのある板。いつもこちらを向き、向きを変えると回る）。`data/characters.json` の `image` に透過 PNG を書くと、絵の代わりにその写真を板に貼る。写真は権利を確かめたものだけを `img/` に置く
- 案内人の QR（`walk?guide=<id>.<合言葉>`）を読むと、話・七賢人のカード・クエストが出る。目的地に着くとクエスト達成
- 図鑑、ポイント（残高と累積、段位）、ランキング（集めた数・累積ポイント・クエスト達成・最速コンプリート・周回数・歩いた距離）
- 見つけた七賢人はパーティーに入り、自分の後ろを付いてくる（最大3人）
- 案内人との知恵くらべ（佐賀クイズ、`data/quiz.json`）。3問中2問で勝ち +50pt、負けると使えるポイントから −30pt（累積は減らない）。ゆかりの七賢人がパーティーにいるとヒント
- 図鑑はエリアごと（`data/chapters.json`）。前のエリアをコンプリートすると次が開く。コンプリートすると周回になり、タイムと歩いた距離を記録する。周回のポイントは1日1回まで
- 周回は SAGATOCO（佐賀県公式ウォーキングアプリ）のコース完走・イベントのチェックインに合わせた作り。本番は周回の完走を SAGATOCO のイベントとして県に登録してもらい、応援店で使える SAGATOCO のポイントにする構想（公開 API はないので県との調整が前提。デモはつながっていない）
- 同じクエストに挑戦中の人を地図に出す（デモでは架空の参加者）
- ガチャ（`gacha.js`、デモ決済で実際の支払いはない）。払った金額と同じだけお店で使えるポイントが付き、1回引ける。1回 ¥300 から回すほど安くなる（最低 ¥150）。持っているものも出る（かぶりは +10pt）。買ったポイントは累積に入れない
- 期間限定ブースト（`events.js`、`data/events.json`）。十日恵比須大祭（2027年1月9〜10日、例年の日付で仮置き）の間はポイント2倍、ガチャのレア2倍。`?date=2027-01-09` で試せる
- `?sages=all` を付けると、七賢人がはじめから全員出る（確かめ用）

**デモ版の制約**：記録はブラウザ（localStorage）にだけ保存する。案内人の合言葉もブラウザで照合するだけ。案内人とランキングのほかの参加者は架空。本番は Worker + D1 に記録を置き、合言葉はサーバーで検証して日替わりにする。ポイントを商店街で使えるようにするなら、扱い（資金決済法・景品表示法）を事務局と確認する。

## 確認できていないこと

- **実機で試していない**：現在地、「着いた」の判定、スマホの向きのセンサー、カメラ
  - かざすモードで、映像の中の明るい星・月と、重ねた印の位置が合うか。ずれるなら `sky.js` の `AR_FOV_DEG`（画角）と方位を調整する
  - iOS は HTTPS でないと向きのセンサーの許可を求められない。デプロイして試す
  - 方位は iOS の `webkitCompassHeading`（磁北基準）、Android の `deviceorientationabsolute` を使う。縦持ちで背面カメラを向けた方角と合っているか確かめる
  - 佐賀の磁気偏角を西に 7.5° として真北に直している（推定値）
- 恵比寿さんの座標は台帳の値。現地で測り直す
- 水害の年表は佐賀市全体の記録。その地点で何cm浸かったかは分かっていない
- 歴史のクイズ（データにはある）は、まだ画面に出していない
- 天の川は描いていない。恒星の固有運動も計算していない
