# planning — 企画資料

ハッカソンで作るものの企画をまとめる場所です。

## 企画の概要

- テーマ：「私たちしか知らない“佐賀の魅力”」
- アイデア：佐賀市内の恵比寿さんを位置情報で巡るゲーム
  - 恵比寿さんを、その場所の「時間の窓」として扱う。前に立つと、恵比寿さんが見てきた歴史・水害・夜空が見える（詳細は [concept.md](./concept.md)）
  - 恵比寿さんに近づくと「お題」が出る。お題は地元の人しか知らない裏話や歴史から作る
  - 正解すると恵比寿さんに認めてもらえ（福を授かり）、裏話と近くのお店の「福クーポン」が解放される
  - お店で画面を見せ、店員さんが「使用済み」を押してクーポンを使う
- 試作「えびすさんが歩く」：えびすさんと佐賀の七賢人が AR で道を歩き、像の場所まで行くと集まって動き出す。案内人のクエスト、ガチャ、記念撮影つき（[ebisu-walk.md](./ebisu-walk.md)）
- 名前は未定（仮：えびす時空さんぽ）。「〇〇 Go」はポケモンGOを連想させるので使わない
- 恵比寿さんは「倒す」敵にしない。地元の人が大事にしている神様なので、「挑む」「認めてもらう」と表現する
