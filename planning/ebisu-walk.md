# さがもん！Go！ — 機能のまとめ

製品名は「さがもん！Go！」。AR で歩く画面は「えびすさんが歩く」と呼ぶ。2026-11-15 時点の試作（`prototype/sanpo/walk`）でできていることをまとめる。作り方やファイルの役割は [prototype/sanpo/README.md](../prototype/sanpo/README.md) にある。

- 公開先（試作）：https://ebisu-sanpo.midnight480.workers.dev/prototype/sanpo/walk
- ブランチ：`feature/ebisu-walk`。PR #1・#2 で main にマージ済み、本番にもデプロイ済み（2026-11-15）
- ハッカソンの試作なので、決済はデモ（実際の支払いは起きない）、ほかの参加者やランキングの相手は架空

## ひとことで

> **佐賀の町を歩くと、えびすさんと佐賀の七賢人が道を歩いている。像の前まで行って写真を撮ると、その像も動き出す。**

[concept.md](./concept.md) の「恵比寿さんは時間の窓」を、集める・歩く・仲間と回る遊びに広げたもの。

## 体験の流れ

1. はじめに好み（好きなこと・歩く量）を聞く
2. スマホをかざすと、えびすさんが本物の道に沿って歩いている（AR。カメラ映像に板ポリゴンを重ねる）
3. 町の案内人（おばあちゃんなど）の QR を読むと、話を聞けて、好みに合わせたクエストがもらえる
4. えびす像の場所まで行くと図鑑に登録され、ポイントがもらえる。写真を撮ると、その像が動き出す
5. えびす像を 10 体集めるごとに、佐賀の七賢人が一人仲間になり、後ろに付いてくる
6. 七賢人と記念撮影。ポイントはお店で使う想定
7. 図鑑がそろわない人はガチャ（デモ決済）でも集められる

## 機能

### AR で歩く

- えびすさんが、OpenStreetMap の徒歩ルートに沿って本物の道を歩く。スマホの向き（ジャイロ）とカメラ映像に合わせて描く
- キャラクターは板ポリゴン調（白い縁取りと厚みのある板）。進む向きに合わせて、正面・左向き・右向きの絵に回って替わる
- 背の高さは実寸：えびす像 0.6m、大隈重信 1.80m、ほかの七賢人 1.57m（記録がない人は幕末の成人男性の平均）
- 地図を押すと、そこに立ったことにできる（会場で歩かずに見せるため）

### えびす像（828体）

- 公式サイト「佐賀恵比須」の一覧（全 9 ページ）と各像のページから、828 体の名前・写真の場所・位置・住所を集めた（`prototype/sanpo/data/ebisu-catalog.json`）
  - 名前があるのは 177 体。ほかは一覧どおり「名称不明（No.番号）」
  - 位置が入ったのは 826 体。蓮池町の 2 体はサイトの位置が佐賀市の外を指していたので、場所には置かない（ガチャと図鑑だけ）
- 本当の場所に像が立っている。近くの像（150m 以内の 12 体まで）は AR で見える。押すと「あと○m」
- そばまで行く（30m 以内）と図鑑に登録し、ポイントがもらえる
  - 図鑑に登録：レア度に応じて N 10pt／R 15pt／SR 20pt／SSR 30pt（ガチャで持っていた像はなし）
  - 現地ボーナス：+20pt（その像にはじめて行ったとき）
- その場で写真を撮ると、撮った写真が板になって、像のまわりを歩き出す（+20pt）。写真は端末の中だけに置き、どこにも送らない。次に近くに来たときも歩いている
- 地図にはレア度の色で全部の像の印が出る（集めた像は濃く）
- 図鑑：レア度と「持っている」で絞り込み。まだの像は写真をぼかし、町名だけをヒントに出す。集めた像は住所と「現地で会えた」の印
- デモの 3 体（八坂成就恵比須・文字鯛恵比須・寶富恵比須）は、歴史のお題や周回にも使う

### 佐賀の七賢人

- えびす像を 10 体集めるごとに一人仲間になる。N → R → SR → SSR の順で、70 体で全員そろう
- 仲間は最大 3 人のパーティーで、後ろに付いてくる。道で会うとパーティーに戻る
- 知恵くらべのヒントをくれる、クエストで連れて行く、記念撮影に一緒に写る
- 板の顔は本人の肖像写真（国立国会図書館「近代日本人の肖像」、`prototype/sanpo/img/sages/`）。描いた体に、顔を楕円に切り抜いてはめる。島義勇は肖像がないので絵の顔

### レア度

デモ用に勝手に付けた。出会いやすさ・ポイント・ガチャの演出が変わる。

| | 七賢人 | えびす像 |
| --- | --- | --- |
| SSR | 鍋島直正 | 八坂成就恵比須、踊り恵比須、雲上恵比須 ほか（13体） |
| SR | 大隈重信、江藤新平 | 文字鯛恵比須 ほか（52体） |
| R | 佐野常民、副島種臣 | 名前のある像の多く（163体） |
| N | 島義勇、大木喬任 | 寶富恵比須、名前のない像（600体） |

### 案内人とクエスト

- 町の案内人（架空）の QR を読むと、話・クエスト・知恵くらべ（佐賀クイズ）
- クエストは、最初に聞いた好みに合わせて、その場で作る。6 種類：会いに行く／順にめぐる／時間内に着く／七賢人を連れて行く／決まった距離を歩く／像の前で見て答える
- 歩く量（少し・ふつう・たっぷり）で、距離・めぐる数・制限時間・ポイントが変わる
- 知恵くらべ：3 問中 2 問で勝ち。負けると使えるポイントが減る（累積は減らない）
- 同じ種類のクエストに挑戦中の人が地図に出る（デモでは架空）

### ポイントとランキング

- 使えるポイント（お店で使う想定）と累積ポイント（段位：えびす見習い → えびす通 → えびす名人）
- ランキング：集めた数・累積ポイント・クエスト達成・最速コンプリート・周回数・歩いた距離
- エリアは第 1 弾（柳町・材木）から順に開く。周回にはタイムと距離を記録し、SAGATOCO のような 1 日の回数制限
- 十日恵比須大祭（1/9〜1/11）の期間はポイント 2 倍・ガチャのレアが出やすい

### ガチャ（デモ決済）

- 払った金額と同じだけ使えるポイントが付き、1 回引ける。¥300 から回すほど安くなる（最低 ¥150）。かぶりも出る
- 出るのはえびす像だけ。まずレア度（N 60%／R 25%／SR 12%／SSR 3%）を決めて、その中から 1 体
- 演出：ガチャガチャ → カプセル → タップで開けてクラッカーでパーン。レア度ごとに色・光・紙吹雪・効果音が変わる
  - 予告（機械が光る）、昇格（下の色のカプセルから化ける）、どんでん返し（N のふりをして、ゴゴゴ… → 雷 → SR・SSR）

### 記念撮影

- 前のカメラに、パーティーの七賢人とえびすさんを並べて撮る。指で動かし、大きさを変えられる
- 写真の下に題名・日付・一緒に写った人の帯。保存・共有は本人が押したときだけ

## 発表で使う URL

| URL | 見せられるもの |
| --- | --- |
| `walk?gacha=SSR&reversal=1` | どんでん返しで SSR が出る |
| `walk?gacha=SR` など | そのレア度を必ず出す |
| `walk?guide=houtomi.tsuri-2015` | 案内人の QR を読んだところから |
| `walk?sages=all` | 七賢人を全員道に出す |
| `walk?views=test` | 板の向き（正面・左・右）の確認 |
| `walk?date=2027-01-10` | 十日恵比須大祭のブースト |

## 本番に向けて確認すること

- 本物のカメラで、現地の写真を撮って像が動き出すか（試作では画像を渡して代わりに確かめた）
- 公式サイトの位置は住所から変換した値かもしれず、現地とずれることがある。デモで使う像は、現地で測り直す

- えびす像の写真と位置は、恵比須DEまちづくりネットワークの公式サイトから使っている。一般に公開する前に、使い方を相談する（写真はリポジトリに保存せず、公式サイトから表示している）
- 島義勇だけは国立国会図書館に肖像がなく、絵の顔のまま
- 記録はブラウザの中だけ（localStorage）。本番は Worker + D1 に置き、ランキングを本物にする
- 決済は本番なら決済代行（Stripe など）を Worker 経由でつなぐ
- 公開先は今 Cloudflare Access を外している（誰でも見られる）
